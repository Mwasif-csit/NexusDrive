# NexusDrive — by ByteNexus

A clean, fast, privacy-first **Drive-to-Drive Cloner, Direct Uploader & Cloud Manager** built using **Pure HTML5, CSS3, and Vanilla JavaScript**.

---

## 🔒 Zero-Data Retention Promise
- **No Files Stored**: NexusDrive never stores, reads, or caches your personal files.
- **Zero Password Access**: Your credentials stay protected with official account sign-in.
- **Direct Cloud Transfer**: Files move directly inside the cloud without passing through external servers.

---

## 🚀 How to Run & Deploy
1. **Local Run**: Double-click `START_LIVE_SERVER.bat` or run `python -m http.server 5000` and open `http://localhost:5000`.
2. **Live Deployment**: Drop this folder onto **Netlify Drop**, **GitHub Pages**, or **Vercel**.
